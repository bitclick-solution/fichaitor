# Encargo para la sesión de diseño

La sesión de diseño es independiente de esta. Este documento le da el contexto mínimo.

## Qué se diseña

Identidad visual propia (no la de Bitclick) y las pantallas del producto, para móvil primero.

Orden de pantallas:

1. Diagnóstico público: entrada y resultado. Es la pantalla que más pesa en la captación desde TikTok.
2. Alta y conexión con Google.
3. Vinculación de WhatsApp.
4. Inicio.
5. Bandeja de propuestas.
6. Reseñas.
7. Calendario de fechas clave.
8. Ajustes.
9. Conversaciones de WhatsApp (son el producto; se maquetan igual que las pantallas).

## Para quién

Dueños de negocios locales, sobre todo hostelería. Usan el móvil, no tienen tiempo y no conocen la jerga de SEO.

## Contenido y comportamiento

- Qué muestra y hace cada pantalla: [04-ux-conversacional.md](04-ux-conversacional.md), sección 6.
- Tono y ejemplos de conversación: [04-ux-conversacional.md](04-ux-conversacional.md), secciones 1 a 4.
- Recorrido completo: [01-flujos.md](01-flujos.md).

## Restricciones

- Web instalable (PWA), no app nativa.
- Cada pantalla define sus estados: vacío, cargando, error, sin conexión con Google y plan sin esa función.
- Contraste AA y objetivos táctiles de 44 px.

## Pendiente de decidir en esa sesión

- Nombre comercial.
- Dirección visual. Las dos pruebas hechas el 2026-11-11 (clara con verde, y oscura con amarillo) se descartaron: no gustó el estilo. Conviene partir de 2 o 3 referencias que aporte el propietario.
